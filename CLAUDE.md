# LiteEdit (fork)

Native macOS editor in Swift/AppKit. This is `fedeandri/lite-edit`, a fork of
`arietan/lite-edit` — **do not open pull requests upstream.**

Read first:

- `MEMORY.md` — project state, recent changes, key files, known issues
- `docs/workspaces-and-windows.md` — how folders, `.code-workspace` files, windows, sessions,
  and Open in Terminal work, and how to test them

Build and install: `./build.sh`, then the install block at the end of
`docs/workspaces-and-windows.md`.
